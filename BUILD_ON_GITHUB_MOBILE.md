# NEON BREACH 0.7.0 — baixar pelo Android

1. Abra [Actions do NEON BREACH](https://github.com/Coca69643/Neon-Breach/actions).
2. Escolha a execução mais recente de **Build NEON BREACH APK** que esteja verde.
3. Em **Artifacts**, baixe `neon-breach-debug-apk`.
4. Extraia o ZIP e instale o APK no Android. Se já existir uma versão com assinatura diferente, desinstale-a primeiro.

## Controles da 0.7.0

- Arraste no lado esquerdo para se mover.
- Arraste a partir do lado direito para mirar e mantenha o toque para disparar.
- Aproxime-se de cada terminal e use **DESATIVAR RELÉ**.
- Desative os três relés e neutralize as quatro unidades hostis; depois alcance o marcador verde de extração.
- Use **PAUSAR** para suspender a operação; você pode retomá-la, reiniciá-la ou voltar ao menu.

## Se algo falhar

Um build verde confirma que o APK foi compilado. Não comprova renderização correta, resposta ao toque ou estabilidade no Realme C53. Se houver tela preta, travamento ou botão sem resposta, informe o modelo do dispositivo, versão Android, em qual tela ocorreu e, se possível, anexe o logcat filtrado por `NeonBreach`.

## Escopo da versão

A 0.7.0 inclui menu, HUD, pausa, resultados e a missão Protocolo de Ruptura. Ainda é um protótipo: os modelos são malhas básicas geradas por código, e o jogo precisa de teste físico no aparelho-alvo.
