# Repository instructions for AI coding agents

Before inspecting or changing implementation code, read `docs/DEVELOPMENT_PROTOCOL.md` in full and follow its required sequence and stop conditions.

For asset acquisition or art-pipeline work, also read `docs/ASSET_PIPELINE_CC0.md`. Verify the license for the exact downloaded package and do not infer rights from a creator name or third-party catalog.

Do not:
- edit source before auditing the current branch and relevant call paths;
- mark code presence or a successful APK build as proof of gameplay correctness;
- weaken tests to make an implementation pass;
- claim a feature, device test, or downloadable artifact is complete without evidence;
- merge work while meaningful review findings or acceptance criteria remain unresolved.

All changes must include explicit acceptance criteria and a truthful handoff describing what was built, what was tested, what failed, and what remains untested.
