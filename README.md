# Projeto Arena

MOBA 3D mobile para Android, com Flutter + Flutter Scene. Offline, landscape e renderização 3D integrada ao Flutter GPU / Impeller.

## Log de atualizações


- **1.7.6 (68) — verticalidade e disputa de território:** duas rotas elevadas com escadas e colisão por nível; barricadas destrutíveis abrem interiores; reator central contestável concede +12% de dano e recompensa de captura; espadas CC0 distintas anexadas ao osso Palm.R de Lyra, Bastion e Kairo; GLB masculino de Kairo validado. CI e teste físico da nova build pendentes.
- **1.7.4 (66) — arena expandida:** três rotas, rio, pontes, acessos laterais e câmera de ação. A revisão visual ainda precisava de validação no aparelho.
- **1.7.3 (65) — câmera de combate:** enquadramento 3/4 mais baixo e próximo do herói; escalas ampliadas para leitura mobile.
- **1.7.2 (64) — migração Flutter Scene:** runtime 3D migrado para Flutter; FSM Dart; prévia 3D de Lyra, Bastion e Kairo.
